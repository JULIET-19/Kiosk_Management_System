# Kiosk_Management_System
A Python command-line application for managing a small kiosk inventory and recording sales.

## Features

* Create a kiosk and owner profile
* View available stock
* Add new products
* Restock existing products
* Sell products
* Check available quantities
* Record sales
* Generate a sales report
* Calculate total revenue
* Identify unique products sold
* Identify the best-selling product
* Search products using partial names
* Save inventory to a text file
* Load inventory when the program starts
* Save sales history to a separate text file

## How to Run

Make sure Python is installed.

Clone the repository and run:

```bash
python kiosk_manager.py
```

The program will create and use text files to save inventory and sales information.
